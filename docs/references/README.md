# Reference Notes

This directory stores project-facing notes for external references that inform `mac-agent`'s design.

These files are intentionally not full mirrors of third-party documentation. Instead, each note records:

- the canonical source URL
- access date
- why the source is authoritative
- the parts of the source that matter to this repository
- related implementation notes for `mac-agent`
